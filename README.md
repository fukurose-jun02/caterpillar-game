# 🐶 けいさつけんがにげろ！

BabyBusの警察犬キャラクターがにじいろイモムシから逃げるブラウザゲームです。

## 遊び方

- **⭐スター**を集めながらイモムシから逃げよう！
- ❤️ライフが3回なくなるとゲームオーバー
- スターを10個集めるたびにイモムシが増える

## 操作方法

| 環境 | 操作 |
|------|------|
| パソコン | 矢印キー or WASD |
| スマホ | 画面ドラッグ or 十字ボタン |

## 遊ぶ方法

[GitHub Pages で公開中](https://YOUR_USERNAME.github.io/caterpillar-game/)

- HTML / CSS / JavaScript のみ（ライブラリなし）
- Canvas API でゲーム描画
